# FEC Check (Morocco)

Free Odoo module that checks Moroccan accounting data against CNC opinion no. 24 (June 2023) and the CGNC.

It runs 36 read-only checks on settings, entries, invoices, partners and bank, and tells what to do for each anomaly.
It changes no accounting data, sends nothing outside the database and needs no activation key. It does not generate the FEC file.

- Branches: `18.0`, `19.0`

The module is in `fec_check_ma/`. It works on Odoo.sh and on your own servers, not on Odoo Online.
